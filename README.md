# Desarrollo-Aquasmart-Movil

#### Clonar repositorio HTTPS.

`git clone https://github.com/SebiceC/Desarrollo-Aquasmart-Movil.git `

#### Entrar a la carpeta del frontend móvil

`cd Desarrollo-Aquasmart-Movil/frontendMobile`

#### Instalar dependencias

`npm install`

#### Ejecutar el frontend móvil

#### `npm start` o `npx expo start --clear`
